## ۱. جدول‌های احراز هویت

از پکیج `@convex-dev/auth/server` استفاده شده و شامل جداول زیر است:

| جدول | توضیح |
|------|-------|
| `authAccounts` | حساب‌های احراز هویت (OAuth, Email, Guest) |
| `authSessions` | نشست‌های فعال |
| `authRefreshTokens` | توکن‌های بازیابی |
| `authVerificationCodes` | کدهای تایید OTP |
| `authRateLimits` | محدودیت نرخ درخواست‌ها |

> ⚠️ این جدول‌ها توسط Convex Auth مدیریت می‌شوند و نباید مستقیماً ویرایش شوند.

## ۲. کاربران (`users`)

```typescript
users: defineTable({
  name:               v.optional(v.string()),    // نام
  lastName:           v.optional(v.string()),    // نام خانوادگی
  image:              v.optional(v.string()),    // تصویر پروفایل
  email:              v.optional(v.string()),    // ایمیل
  emailVerificationTime: v.optional(v.number()), // زمان تایید ایمیل (timestamp)
  isAnonymous:        v.optional(v.boolean()),   // کاربر مهمان
  role:               v.optional(v.string()),    // نقش کاربر (admin, manager, operator, user)
  phone:              v.optional(v.string()),    // شماره تلفن
  nationalCode:       v.optional(v.string()),    // کد ملی
  address:            v.optional(v.string()),    // آدرس
  postalCode:         v.optional(v.string()),    // کد پستی ۱۰ رقمی
  avatar:             v.optional(v.string()),    // آواتار
  birthDate:          v.optional(v.string()),    // تاریخ تولد (شمسی)
  gender:             v.optional(v.string()),    // جنسیت (male/female)
  isActive:           v.optional(v.boolean()),   // فعال/غیرفعال
  isLocked:           v.optional(v.boolean()),   // قفل حساب
  lastLogin:          v.optional(v.number()),    // آخرین زمان ورود (timestamp)
  lockScreenTime:     v.optional(v.number()),    // زمان قفل صفحه (دقیقه)
  createdAt:          v.optional(v.number()),    // تاریخ ایجاد (timestamp)
  updatedAt:          v.optional(v.number()),    // تاریخ بروزرسانی (timestamp)
})
```

**ایندکس‌ها:**

| نام ایندکس | فیلدها | کاربرد |
|------------|--------|--------|
| `email` | `[email]` | جستجوی کاربر با ایمیل |
| `by_role` | `[role]` | فیلتر بر اساس نقش |
| `by_isActive` | `[isActive]` | فیلتر کاربران فعال/غیرفعال |

## ۳. محصولات (`products`)

```typescript
products: defineTable({
  name:               v.string(),              // نام محصول (اجباری)
  slug:               v.string(),              // اسلاگ یکتا (URL-friendly)
  description:        v.string(),              // توضیحات کامل
  shortDescription:   v.optional(v.string()),  // توضیحات کوتاه
  price:              v.number(),              // قیمت اصلی (تومان)
  salePrice:          v.optional(v.number()),  // قیمت فروش ویژه
  stock:              v.number(),              // موجودی انبار
  stockAlert:         v.optional(v.number()),  // آستانه هشدار موجودی کم
  images:             v.array(v.string()),     // لینک تصاویر (حداکثر چندتا)
  categoryId:         v.id("categories"),      // 🔗 ارجاع به دسته‌بندی
  tags:               v.array(v.string()),     // برچسب‌ها
  brand:              v.optional(v.string()),  // نام برند
  weight:             v.optional(v.number()),  // وزن (گرم)
  features:           v.optional(v.any()),     // ویژگی‌های داینامیک (JSON)
  isFeatured:         v.boolean(),             // محصول ویژه
  isActive:           v.boolean(),             // فعال/غیرفعال
  views:              v.number(),              // تعداد بازدید
  rating:             v.optional(v.number()),  // میانگین امتیاز (۰-۵)
  reviewCount:        v.optional(v.number()),  // تعداد نظرات
  seoTitle:           v.optional(v.string()),  // عنوان SEO
  seoDescription:     v.optional(v.string()),  // توضیحات SEO
  lastPriceUpdate:    v.optional(v.number()),  // آخرین تغییر قیمت
  createdAt:          v.number(),              // تاریخ ایجاد
  updatedAt:          v.number(),              // تاریخ بروزرسانی
})
```

**ایندکس‌ها:**

| نام ایندکس | فیلدها | کاربرد |
|------------|--------|--------|
| `by_slug` | `[slug]` | جستجو با اسلاگ (URL) |
| `by_category` | `[categoryId]` | محصولات یک دسته |
| `by_isActive` | `[isActive]` | فیلتر فعال/غیرفعال |
| `by_isFeatured` | `[isFeatured]` | محصولات ویژه |
| `by_price` | `[price]` | سورت بر اساس قیمت |
| `by_views` | `[views]` | پربازدیدترین‌ها |

## ۴. دسته‌بندی‌ها (`categories`)

```typescript
categories: defineTable({
  name:             v.string(),                                    // نام دسته
  slug:             v.string(),                                    // اسلاگ
  description:      v.optional(v.string()),                       // توضیحات
  image:            v.optional(v.string()),                       // تصویر
  parentId:         v.optional(v.id("categories")),               // 🔗 دسته والد (درختی)
  level:            v.number(),                                    // سطح درخت (0 = ریشه)
  order:            v.number(),                                    // ترتیب نمایش
  isActive:         v.boolean(),                                   // فعال/غیرفعال
  features:         v.optional(v.array(v.object({                  // ویژگی‌های داینامیک
    key:  v.string(),
    label: v.string(),
  }))),
  seoTitle:         v.optional(v.string()),                       // عنوان SEO
  seoDescription:   v.optional(v.string()),                       // توضیحات SEO
})
```

**ایندکس‌ها:**

| نام ایندکس | فیلدها | کاربرد |
|------------|--------|--------|
| `by_parent` | `[parentId]` | زیردسته‌های یک دسته |
| `by_level` | `[level]` | فیلتر بر اساس سطح |
| `by_isActive` | `[isActive]` | دسته‌بندی‌های فعال |
| `by_slug` | `[slug]` | جستجو با اسلاگ |

> 🌳 **ساختار درختی:** از فیلد `parentId` و `level` برای ایجاد سلسله‌مراتب نامحدود استفاده می‌شود. `parentId = undefined` یعنی دسته ریشه.

## ۷. سفارشات (`orders`)

```typescript
orders: defineTable({
  orderNumber:    v.string(),            // شماره سفارش یکتا
  userId:         v.id("users"),         // 🔗 کاربر
  items:          v.array(v.object({     // آیتم‌های سفارش
    productId:  v.id("products"),        // 🔗 محصول
    name:       v.string(),              // نام محصول در زمان سفارش
    quantity:   v.number(),              // تعداد
    price:      v.number(),              // قیمت واحد
    total:      v.number(),              // قیمت کل آیتم
  })),
  subtotal:       v.number(),            // مبلغ خالص
  tax:            v.number(),            // مالیات
  shippingCost:   v.number(),            // هزینه ارسال
  discount:       v.number(),            // مبلغ تخفیف
  total:          v.number(),            // مبلغ نهایی
  status:         v.union(               // وضعیت سفارش
    v.literal("pending"),
    v.literal("paid"),
    v.literal("processing"),
    v.literal("shipped"),
    v.literal("delivered"),
    v.literal("cancelled"),
  ),
  paymentStatus:  v.union(               // وضعیت پرداخت
    v.literal("pending"),
    v.literal("paid"),
    v.literal("failed"),
    v.literal("refunded"),
  ),
  paymentMethod:  v.string(),            // روش پرداخت
  transactionId:  v.optional(v.string()),// شماره تراکنش
  shippingMethod: v.string(),            // روش ارسال
  trackingCode:   v.optional(v.string()),// کد رهگیری پست
  address:        v.string(),            // آدرس ارسال
  postalCode:     v.string(),            // کد پستی
  notes:          v.optional(v.string()),// یادداشت
  receiveSms:     v.optional(v.boolean()),// دریافت پیامک
  department:     v.optional(v.string()),// دپارتمان مسئول
  createdAt:      v.number(),            // تاریخ ایجاد
  updatedAt:      v.number(),            // تاریخ بروزرسانی
})
```

**ایندکس‌ها:** `by_user`, `by_orderNumber`, `by_status`, `by_createdAt`

> **وضعیت سفارش (State Machine):**
> ```
> pending → paid → processing → shipped → delivered
> pending → cancelled
> paid → cancelled (بازپرداخت)
> ```

```typescript
tickets: defineTable({

  updatedAt:       v.number(),
})
```

**ایندکس‌ها:** `by_user`, `by_status`, `by_assignee`

> **وضعیت تیکت (State Machine):**
> ```
> open → in_progress → answered → closed

> ```

## ۱۵. پیام‌های چت (`messages`)

```typescript
messages: defineTable({
  chatId:       v.string(),              // شناسه مکالمه (ترکیب دو کاربر)
```

## نکات فنی مهم

### ۱. `v.any()` در فیلدها
برخی فیلدها مانند `features` در محصولات و `value` در تنظیمات از `v.any()` استفاده می‌کنند.
این بدان معناست که **اعتبارسنجی نوع در سطح اسکیما انجام نمی‌شود** و باید در سطح application اعتبارسنجی شوند.

### ۲. شناسه‌های ارجاعی
تمام فیلدهای `v.id("tableName")` ارجاع به جدول دیگری هستند.
Convex تضمین می‌کند که مقدار این فیلدها یک شناسه معتبر باشد ولی **完整性 (integrity)** را تضمین نمی‌کند — یعنی اگر رکورد والد حذف شود، فرزندان حذف نمی‌شوند.

### ۳. `schemaValidation: false`
در انتهای اسکیما تنظیم شده. یعنی اعتبارسنجی دقیق اسکیما غیرفعال است.
این ممکن است برای سازگاری با داده‌های قدیمی باشد.

### ۴. جداول جدید اضافه شده
جدول‌های `giftCards` و `activityLogs` نیز در اسکیما وجود دارند ولی ساختار دقیقشان در بالا آورده نشد.
برای اطلاعات بیشتر فایل `src/convex/schema.ts` را ببینید.
